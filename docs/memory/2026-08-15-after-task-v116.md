## 11. Team learning

**The most dangerous argument is one that is accepted and then silently ignored.** A
function that validates `method` with `match.arg()` *looks* guarded — `match.arg` proves the
value is legal, not that it is used. The test that matters is not "does it return the right
shape" but "does the result change when the argument changes". Cheap rule for next time:
for any forwarded option, assert that two different values produce two different answers.
